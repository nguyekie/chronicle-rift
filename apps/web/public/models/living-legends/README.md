# Mô hình Huyền Thoại Sống

Runtime tải `abyss-dragon.glb`, `cosmic-empress.glb` và `star-forge.glb` trong thư mục này. Nếu thiếu model, game tự dùng hiệu ứng ảnh 2.5D để trận đấu không bị gián đoạn.

Mỗi model cần có các clip `Summon`/`Intro`, `Idle`, `Attack`/`Ultimate`; Y-up, nhìn về +Z, dung lượng khuyến nghị dưới 8 MB và texture tối đa 2048 px.
